# Verificadores públicos

Scripts versionados para integridade, documentação, segurança, arquitetura, SEO e analytics. `npm run verify` executa os gates atualmente aplicáveis e testes adversariais do harness. Os scripts de SEO e analytics parcialmente preparados indicam `NÃO APLICÁVEL` quando faltar aplicação. Ferramentas específicas da máquina ficam em `.local/` e não podem ser dependência do CI.
