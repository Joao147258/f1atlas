# Estratégia de integrações

Avaliar fornecedor por: licença/redistribuição, cobertura 2025–27, custo, latência, limites, qualidade, estados provisórios, histórico e termos de uso.

**Candidatos de pesquisa:** Jolpica-F1 e OpenF1, sem afirmar aprovação para utilização comercial. Nenhuma integração implementada ou licenciada nesta fundação.

**Port/adapters apenas se necessário:** preservar contrato interno de dados, validar payloads, traduzir IDs e erros; não espalhar modelos externos pelo domínio. Ver `docs/specs/product/SPEC-DATA-001.md`.
