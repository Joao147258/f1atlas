# Design system

Tokens semânticos de cor, tipografia, espaçamento, foco, borda e gráficos serão definidos após prototipação. Não replicar cores ou identidade visual oficial. Componentes iniciais: calendário, resultado, classificação, filtro, gráfico, timeline, capítulo, fonte e estados de erro.

Todo componente deve explicitar estados, responsividade e atributos de acessibilidade antes de ser considerado pronto.
