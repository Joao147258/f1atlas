# Governança de capacidades e skills

- `skills/`: 18 capacidades sob demanda e reutilizáveis, diretamente integradas aos agentes.
- `templates/`: modelos padronizados de referência para agentes e skills.

> **Nota sobre Agentes:** A fonte única e canônica dos 11 subagentes do projeto é `.gemini/agents/`, aproveitando o mecanismo nativo de descoberta do executor. Consulte `docs/development/agent-governance.md` e a SPEC-GOV-001.
